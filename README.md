# 우리 반 직업 배정소

학급 1인 1역을 학생 지망 기반으로 자동 배정해 주는 도구입니다.

> **👉 실제 배포에는 [`apps-script/`](apps-script/) 버전을 권장합니다.**
> 구글 스프레드시트 기반으로 학생 명단 검증·회차 관리·결과 공개 제어까지 갖춘 실사용 버전이며,
> 배포·업데이트 방법은 [apps-script/README.md](apps-script/README.md)에 있습니다.
>
> 아래 내용은 대안 구현인 **Firebase 버전**(루트 `index.html`)에 대한 설명입니다.

---

파일 하나(`index.html`)로 동작하며, 서버 주소를 설정하면 **학생들이 각자 기기(폰·태블릿·컴퓨터)에서 학급 코드로 접속**해 지원할 수 있습니다.

## 두 가지 동작 모드

| | 원격 모드 (권장) | 로컬 모드 |
|---|---|---|
| 조건 | `index.html`의 `SYNC_SERVER_URL` 설정 | 설정 없이 그대로 사용 |
| 학생 접속 | 각자 기기에서 학급 코드/링크로 접속 | 선생님 기기 한 대에서 돌아가며 입력 |
| 데이터 위치 | 지원서·직업·배정 결과는 서버, 성실도 점수·기록은 선생님 기기 | 전부 그 브라우저에만 저장 |

`SYNC_SERVER_URL`이 비어 있으면 화면 상단에 로컬 모드 경고 배너가 표시됩니다.

## 배포 방법 (원격 모드, 약 10분)

### 1. Firebase Realtime Database 만들기 (무료)

1. https://console.firebase.google.com 에서 Google 계정으로 로그인 → **프로젝트 만들기** (이름 자유, 애널리틱스 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: `asia-southeast1` (싱가포르) 권장
   - 보안 규칙: 일단 "잠금 모드"로 만들기
3. **규칙** 탭에서 아래로 교체하고 게시:

```json
{
  "rules": {
    "classes": {
      "$code": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

4. **데이터** 탭 상단에 표시되는 주소를 복사합니다.
   예: `https://my-project-default-rtdb.asia-southeast1.firebasedatabase.app`

### 2. index.html에 주소 넣기

`index.html` 상단의 이 부분에 복사한 주소를 붙여넣습니다:

```js
const SYNC_SERVER_URL = 'https://my-project-default-rtdb.asia-southeast1.firebasedatabase.app';
```

### 3. 웹에 올리기

GitHub Pages(저장소 Settings → Pages → main 브랜치)나 Netlify 등 아무 정적 호스팅에 `index.html`을 올리면 끝입니다.

## 사용 흐름

1. **선생님**: 접속 → "새 학급 만들기" → 학급 이름과 **PIN**(선생님 화면 보호용 비밀번호) 설정 → 6자리 학급 코드 생성
2. **선생님**: 직업 목록 만들기 → "학생 초대" 카드에서 코드 또는 링크를 학생들에게 공유
3. **학생**: 각자 기기에서 링크(또는 코드 입력)로 접속 → 번호+이름, 1·2·3지망, 지원 이유 작성 → 제출
4. **선생님**: 지원 현황 확인(20초마다 자동 새로고침) → "배정 실행하기" → 결과가 학생들 화면에도 공개됨
5. **매달 반복**: 성실도 점수 입력 → "이번 달 마감 & 다음 달 준비"

## 꼭 알아두세요

- **동명이인**: 지원서는 이름으로 구분되므로 반드시 "7번 김민수"처럼 번호를 붙여 제출하게 해주세요. 같은 이름으로 다시 제출하면 경고 후 덮어씁니다.
- **성실도 점수와 지난달 기록은 선생님 기기에만 저장됩니다** (학생에게 공개되지 않음). 학교 컴퓨터는 재부팅 시 초기화되는 경우가 많으니, 배정을 마친 뒤에는 **"전체 백업(JSON)"을 꼭 내려받아 두세요.** 다른 컴퓨터로 옮길 때는 "기존 학급 접속"(코드+PIN) 후 백업 파일을 불러오면 됩니다.
- **보안 수준**: 학급 코드 + PIN은 교실 수준의 보호 장치입니다. 데이터베이스 주소를 아는 사람이 기술적으로 접근하는 것까지 막지는 못하므로, 민감한 개인정보(전화번호, 주민번호 등)는 절대 입력하지 마세요. 이름도 "번호+이름" 정도만 사용하길 권합니다.
- **비용**: Firebase 무료(Spark) 요금제로 학급 수십 개 규모는 충분합니다.
