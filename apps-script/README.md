# 우리 반 직업 배정소 — Apps Script 버전 (배포 권장)

구글 스프레드시트를 데이터베이스로 쓰는 실사용 버전입니다.
학생들은 각자 기기에서 **학급 코드**로 접속해 신청하고, 모든 데이터는 스프레드시트에 쌓입니다.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 백엔드 (스프레드시트 읽기/쓰기, 배정 알고리즘, 인증) |
| `index.html` | 화면 (선생님/학생 공용, 데모 모드 내장) |

## 처음 배포하는 방법

1. 새 구글 스프레드시트 생성 → 메뉴 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 내용 붙여넣기
3. **+ → HTML** 로 파일 추가, 이름은 정확히 `index` → 이 폴더의 `index.html` 내용 붙여넣기
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 생성된 웹 앱 URL(`...script.google.com/.../exec`)을 선생님들께 공유

한 번 배포하면 **여러 학급이 같은 주소를 함께 사용**합니다. 선생님마다 "새 학급 만들기"로 학급 코드와 관리 비밀번호를 만들면 데이터가 학급 코드별로 분리됩니다.

## 이미 배포된 앱을 업데이트하는 방법 (주소·데이터 유지)

1. 기존 스프레드시트 → 확장 프로그램 → Apps Script 열기
2. `Code.gs`와 `index` 내용을 이 폴더의 최신 파일로 교체
3. **배포 → 배포 관리 → (연필 아이콘) → 버전: 새 버전 → 배포**

주소는 그대로 유지되고, 시트에 쌓인 데이터도 그대로입니다.
(주의: "새 배포"를 만들면 주소가 바뀌므로 반드시 **배포 관리에서 기존 배포를 수정**하세요.)

## 이번 검토에서 수정된 내용 (2026-07)

- **동시 제출 보호**: 반 전체가 한꺼번에 신청해도 지원서가 꼬이지 않도록 데이터 변경 요청 전체에 `LockService` 잠금 적용
- **번호 표기 정규화**: 명단에 `1`로 저장된 학생이 `01`로 입력해도 매칭됨 (신청·내 지원서·내 직업 조회 모두)
- **선생님 지원현황 화면 안전성**: 학생 이름에 특수문자가 있어도 성실도/삭제 버튼이 깨지지 않도록 인덱스 참조로 변경, 지원 삭제 전 확인 창 추가
- **추첨 가중치**: 추첨 점수가 문서화된 범위(0~3점)와 일치하도록 수정
- 데모 모드가 실제 백엔드와 같은 번호 매칭 규칙을 쓰도록 통일

## 선생님 안내용 예시 학급 만들기

연수나 소개 자리에서 보여줄 **예시 학급**이 필요하면, 편집기 상단 함수 목록에서
**`seedExampleClass`** 를 선택해 한 번 실행하세요. 직업·학생 명단·지원·성실도·자동배정(공개)까지
모두 채워진 학급이 만들어집니다.

- **학급 코드:** `SAMPLE`  · **관리 비밀번호:** `1234`
- **학생 로그인 예시:** 번호 `1`, 이름 `김하늘`

선생님용은 첫 화면 → 선생님 → "학급 관리"에서 코드+비밀번호로,
학생용은 첫 화면 → 학생 → 코드 입력 후 번호/이름으로 들어가면 됩니다.
다시 실행하면 예시가 처음 상태로 새로 채워지며, 코드가 `SAMPLE`인 학급만 건드리므로
실제 학급 데이터에는 영향이 없습니다.

## "-2209105671999회차" 같은 이상한 회차가 보일 때

예전 버전에서 테스트하며 `Rounds` 시트에 날짜 형식 값이 섞인 낡은 행이 남으면
이런 유령 회차가 나타날 수 있어요. 최신 코드는 이런 잘못된 회차를 자동으로 무시하지만,
시트에서 완전히 지우려면 편집기 상단 함수 목록에서 **`cleanupBadRounds`** 를 선택해 한 번 실행하세요.
정상 회차(1, 2, 3 …)와 그 지원·배정 기록은 그대로 유지됩니다.
(직접 지우려면 `Rounds` 시트에서 `round` 칸이 이상한 행을 삭제해도 됩니다.)

## 알아두면 좋은 점 (설계상 한계)

- **학생 인증은 번호+이름뿐**입니다. 같은 반 친구를 사칭해 신청을 보거나 덮어쓸 수 있어요(교실 수준에서 허용한 절충). 신청 시각이 시트 `Applications`에 남으니 이상하면 확인할 수 있습니다.
- 웹 앱 주소를 아는 사람은 누구나 "새 학급 만들기"를 할 수 있습니다. 시트가 지저분해지면 `Classes` 시트에서 안 쓰는 행을 지우면 됩니다.
- 스프레드시트를 직접 편집할 때는 헤더 행과 열 순서를 바꾸지 마세요.
- 반 규모(수십 명) 사용을 전제로 한 구조입니다. 학교 전체 수백 명이 동시에 쓰면 느려질 수 있어요.
